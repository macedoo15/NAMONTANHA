# Na Montanha — Cardápio

Este projeto é um cardápio estático em HTML/CSS para o bar e drinks "Na Montanha".

## Descrição

O arquivo principal `index.html` apresenta um menu visual responsivo com seções como:

- Bebidas
- Cervejas
- Drinks
- Destilados
- Sobremesas

O layout utiliza estilos internos e fontes do Google Fonts para criar uma apresentação moderna e escura.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Navegue pelas seções usando o menu superior.
3. O site é totalmente estático e não requer servidor ou instalação.

## Estrutura do projeto

- `index.html` — página principal do cardápio.

## Observações

- O projeto é ideal para demonstrar um protótipo de cardápio digital.
- Para personalizar, edite diretamente o conteúdo e estilos em `index.html`.
